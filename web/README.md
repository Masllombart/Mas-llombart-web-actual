# Web nueva Mas Llombart

Sitio estático listo para Netlify (configuración en `../netlify.toml`, carpeta publicada: `web/`).

- 10 páginas HTML con CSS y fuentes integradas; imágenes en `wp-content/uploads/`; dossieres PDF en `docs/`.
- Formularios `contacto` y `presupuesto` gestionados por Netlify Forms (`data-netlify="true"`, honeypot `empresa-web`).
- Las URLs antiguas de WordPress redirigen (301) a las páginas nuevas.
